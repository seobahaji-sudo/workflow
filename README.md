# ورک‌فلو خودکار تولید محتوا و اخبار GTA 6 (Grand Theft Auto VI)

این پروژه اخبار انگلیسی بازی GTA VI را به طور خودکار پیدا کرده، به فارسی روان و سئوشده ترجمه می‌کند و مستقیماً روی سایت شما (وردپرس) قرار می‌دهد.

---

### 📁 پوشه‌ها و فایل‌های پروژه:
- `fetch_and_publish.js`: موتور اصلی بررسی اخبار، ترجمه سئو و ارسال به سایت.
- `config.json`: تنظیمات آدرس سایت و فیدهای خبری.
- `run.bat`: فایل اجرای سریع با یک دابل‌کلیک بدون نیاز به کدنویسی.
- `drafts/`: مقالات تولید شده در دو فرمت HTML و Markdown در اینجا ذخیره می‌شوند.
- `history.json`: سابقه اخبار کار شده برای جلوگیری از ارسال خبر تکراری.

---

### 🌐 نحوه اتصال خودکار به سایت وردپرسی شما:
فایل `config.json` را باز کنید و بخش `site_settings` را با اطلاعات سایتتان پر کنید:
```json
{
  "site_settings": {
    "wp_url": "https://yoursite.com",
    "wp_username": "نام_کاربری_شما",
    "wp_app_password": "رمز عبور برنامه (Application Password)",
    "post_status": "draft"
  }
}
```

> **راهنمای ساخت Application Password در وردپرس:**  
> ۱. در پیشخوان وردپرس به بخش **کاربران > شناسنامه شما (Users > Profile)** بروید.  
> ۲. به پایین صفحه اسکرول کنید تا به بخش **رمزهای عبور برنامه (Application Passwords)** برسید.  
> ۳. یک نام بنویسید (مثلاً `GTA_Bot`) و دکمه **افزودن رمز عبور برنامه جدید** را بزنید.  
> ۴. کد تولید شده (یک عبارت چند کلمه‌ای) را در فیلد `wp_app_password` قرار دهید.
